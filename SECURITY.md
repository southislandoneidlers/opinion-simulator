# Security policy (reconstructed stub)

- Report vulnerabilities privately via GitHub Security Advisories on this
  repository; no public disclosure until a fix ships.
- Credentials must never appear in Project files, logs, tests, or the Renderer.
- Writers refuse non-empty output directories by design.
- Public-release blockers (tracked in docs/roadmap.md): legacy-key rotation,
  secret scan, Git history review, private security contact.
