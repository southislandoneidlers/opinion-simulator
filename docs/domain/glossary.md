# Domain glossary (reconstructed core terms)

> Lost in the 2026-08-24 deletion; core definitions restored from usage.

- **Project**: an open directory holding sources, Personas, question sets,
  Runs, reports, and integrity metadata. Not a single file.
- **Source**: supplied material (v0.x: pasted text) hashed into every claim.
- **Persona Draft / Persona Version**: free-form input organized into fields;
  confirmation produces an immutable Version; later edits create new versions.
- **Persona Inference**: a proposed field value with rationale; excluded until
  accepted; accepted values are labelled separately from direct support.
- **Question Set**: user questions asked of the Persona; Results must answer
  each question in order when valid.
- **Preflight Review**: pre-execution disclosure of outbound material, prompt,
  provider/model, estimate, warnings, disclaimer; approved by plan hash.
- **Sample**: one independent provider response for one Persona within a Run.
  Stability mode produces three.
- **Direct Reaction**: natural-language Persona-voiced response; the primary output.
- **Persona Recommendation**: advice inside the Persona voice; displayed
  separately from System Suggestions.
- **System Suggestion**: AI-system analysis outside the Persona voice.
- **Stability Comparison**: exact normalized comparison of repeated Samples;
  not calibrated confidence.
- **Synthesis**: attributed cross-Persona synthesis over explicitly selected
  Samples; consensus needs ≥2 supporting Samples; not a group quotation.
