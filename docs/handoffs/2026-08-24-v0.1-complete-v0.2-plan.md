   output schema, model/sampling parameters) goes first in what is sent to the
   model; per-Run content (Persona, questions, Source) goes last — to save
   tokens and stay cache-friendly.
2. **Reusable Persona library:** an interface to reuse previously entered/
   confirmed Personas instead of re-typing. Pulled forward from later
   milestones at the user's request.
3. **Non-empty Project directories:** users may designate one folder as a
   single project home; appending new Runs must work there. The current
   empty-target-only guard is too strict for real use. Pulled forward.
