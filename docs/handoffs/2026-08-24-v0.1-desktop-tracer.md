## Goal and result

Start the v0.1 desktop tracer after the user accepted the Synthesis report.
Electron shell with freely navigable stages, pasted-text Source, manually
confirmed Persona, Preflight, one mocked Run, and open-directory JSON/Markdown
artifacts that the v0.0 Python validator accepts.

Live Gemini is an opt-in main-process call resolved only from the process
environment (`GEMINI_API_KEY`); the Renderer receives only
`{ geminiAvailable: boolean }`. OS Keychain storage remains v0.2.

## Structure

- `apps/desktop/`: Electron main/preload/renderer, IPC allow-list, staged UI.
- `packages/core/`: hashing, Persona confirmation, plan/preflight, report, IPC names.
- `packages/project-store/`: open-directory write/read.
- `packages/providers-gemini/`: mock adapter and live generateContent client.

## Decisions

- Mocked Runs never read a credential.
- Renderer sandbox: `nodeIntegration: false`, `contextIsolation: true`, CSP,
  denied navigation/permissions; IPC payload keys matching credential-shaped
  names are rejected.
- Project writer compatibility: writer may be `opinion-simulator-desktop`;
  provider may be `gemini`.
